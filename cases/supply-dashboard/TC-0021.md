preconditions: |
  -   Log in as an Admin user role;
  -   The user has at least 1 SSP endpoint with the 'Indirect suppliers' source type on the Supply dashboard.
steps:
  - id: s-9E6BY5KV
    action: |
      Open the Supply Dashboard menu item
    expected: |
      The 'Supply Dashboard' page is opened
  - id: s-BJER6EXS
    action: |
      Select the existing SSP with the 'Indirect suppliers' source type on the table and click on the 'Clone' button
    expected: |
      The 'Clone source' modal appears and consists of the following elements:

      -   Source name:
          
          -   empty by default, required input;
          -   tooltip: 'Set the source name. It's better to include the name of the supply partner and traffic type to easily recognize it later. E.g., SSPname\_In-App\_Video';
          -   placeholder: 'Enter the name of the new source';
      -   Company Name:
          
          -   required single-select dropdown with the list of existing companies and search input;
          -   the company of the original Supply Source is selected by default;
          -   tooltip: 'Select the Company the source should be linked with';
      -   Region:
          
          -   required single-select dropdown with the search input and list of regions;
          -   the region of the original Supply Source is selected by default;
          -   tooltip: 'Server location. Make sure you have the server in the same region as your partner to avoid timeouts';
      -   Cancel button;
      -   Clone button;
  - id: s-QNZAT9A8
    action: |
      Without making any changes click on the 'Clone' button
    expected: |
      -   'The Source Name field is required.' message appears;
      -   The Source Name field is highlighted in red;
  - id: s-F52XHY5F
    action: |
      -   Add the invalid source name with less than 3 characters;
      -   Click on the 'Clone' button;
    expected: |
      -   'The Source Name must not be greater than 125 characters.' message appears;
      -   The Source Name field is highlighted in red;
  - id: s-57TY6NPV
    action: |
      -   Add the invalid source name with more than 125 characters;
      -   Click on the 'Clone' button;
    expected: |
      -   'The Source Name must not be greater than 125 characters.' message appears;
      -   The Source Name field is highlighted in red;
  - id: s-FVVGT5HP
    action: |
      -   Enter the valid source name;
      -   Change the company and region;
      -   Click on the 'Clone' button;
    expected: |
      After the cloning process is completed, a new modal appears:

      -   The supply source is cloned;
      -   Do you want to review the supply source settings?;
      -   'Yes'/'Cancel' buttons;
  - id: s-R5ZZYBW5
    action: |
      Click on the 'Yes' button
    expected: |
      -   Preloader is displayed for a few seconds;
      -   User is redirected to the cloned endpoint edit page;
  - id: s-1Y2D0P61
    action: |
      Inspect the settings of the cloned endpoint
    expected: "-   The Source name of the cloned endpoint corresponds with the previously added name;\n-   The\_\_Region and Company of the cloned endpoint correspond with the previously selected values and disabled by default;\n-   The status is the same as it was in the copied source;\n-   Source Type toggle - Indirect suppliers and disabled by default;\n-   All other settings are identical to the original endpoint;\n"
