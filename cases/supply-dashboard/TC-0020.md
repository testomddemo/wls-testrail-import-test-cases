preconditions: |
  -   Log in as an Admin user role;
  -   The user has at least 1 SSP endpoint with the 'Direct inventory' source type on the Supply dashboard.
steps:
  - id: s-Z340M351
    action: |
      Open the Supply Dashboard menu item
    expected: |
      The 'Supply Dashboard' page is opened
  - id: s-FWVMVABJ
    action: |
      Select the existing SSP with the 'Direct inventory' source type on the table and click on the 'Clone' button
    expected: |
      The 'Clone source' modal appears and consists of the following elements:

      -   Source name:
          
          -   empty by default, required input;
          -   tooltip: 'Set the source name. It's better to include the name of the supply partner and traffic type to easily recognize it later. E.g., SSPname\_In-App\_Video';
          -   placeholder: 'Enter the name of the new source';
      -   Company Name:
          
          -   required single-select dropdown with the list of existing companies and search input;
          -   the company of the original Supply Source is selected by default;
          -   tooltip: 'Select the Company the source should be linked with';
      -   Region:
          
          -   required single-select dropdown with the search input and list of regions;
          -   the region of the original Supply Source is selected by default;
          -   tooltip: 'Server location. Make sure you have the server in the same region as your partner to avoid timeouts';
      -   Bundle/Domain:
          
          -   **shown only for Supply sources with RON traffic toggle OFF;**
          -   required text field, empty;
          -   tooltip: 'Add bundle or the top domain of your website';
      -   Cancel button;
      -   Clone button;
  - id: s-38JBQF0T
    action: |
      Without making any changes click on the 'Clone' button
    expected: |
      Warnings appear:

      -   The Source Name field is required.;
      -   The Bundle/Domain field is required;
      -   The Source Name and Bundle/Domain fields are highlighted in red;
  - id: s-B96AQN11
    action: |
      -   Add the invalid source name with less than 3 characters;
      -   Enter an invalid bundle or domain into the Bundle/domain field;
      -   Click on the 'Clone' button;
    expected: |
      -   The 'The Source Name must be at least 3 characters.' message appears;
      -   The 'The Bundle/Domain must be a valid bundle or domain.' message appears;
      -   The Source Name and Bundle/Domain fields are highlighted in red;
  - id: s-YMGP49J5
    action: |
      -   Add the invalid source name with more than 125 characters;
      -   Enter a valid bundle or domain into the Bundle/domain field;
      -   Click on the 'Clone' button;
    expected: |
      -   'The Source Name must not be greater than 125 characters.' message appears;
      -   The Source Name field is highlighted in red;
  - id: s-DF9R3NBT
    action: |
      -   Enter the valid source name;
      -   Change the company and region;
      -   Click on the 'Clone' button;
    expected: |
      After the cloning process is completed, a new modal appears:

      -   The supply source is cloned;
      -   Do you want to review the supply source settings?;
      -   'Yes'/'Cancel' buttons;
  - id: s-QZQHM81R
    action: |
      Click on the 'Yes' button
    expected: |
      -   Preloader is displayed for a few seconds;
      -   User is redirected to the cloned endpoint edit page;
  - id: s-MD9CFPWB
    action: |
      Inspect the settings of the cloned endpoint
    expected: "-   The\_\_Source name of the cloned endpoint corresponds with the previously added name;\n-   The\_\_Region and Company of the cloned endpoint correspond with the previously selected values and disabled by default;\n-   The status is the same as it was in the copied source;\n-   Source Type toggle - Direct inventory and disabled by default;\n-   All placements are cloned correctly without changes\n-   All other settings are identical to the original endpoint;\n"
