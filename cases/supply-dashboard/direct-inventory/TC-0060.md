  - id: s-KQRCGKG1
    action: |
      Open the Supply Dashboard menu item
    expected: |
      The 'Supply Dashboard' page is opened
  - id: s-RTT2JA5C
    action: |
      -   Find the existing inventory with several added placements;
      -   Click on the tag value '{number of created placements}'
    expected: |
      The user is redirected to the placements dashboard {inventory name}
  - id: s-2YSVXAX2
    action: |
      Click on the 'Edit source' button
    expected: |
      -   The Edit Supply Source page is opened;
      -   All settings are editable, except:
          
          -   Company;
          -   Source Type;
          -   Region
  - id: s-AXXDQJJK
    action: |
      Change several settings:

      -   Add new source name;
      -   change the traffic type;
      -   add new Margin type value;
      -   change the selected allowed Companies and Allowed Demand sources

      Click the 'Save&Exit' button
    expected: |
      -   'The supply source was updated.' notification is displayed;
      -   The user is redirected to the 'Supply Dashboard' page
  - id: s-80PRB9Y4
    action: |
      Find the updated Direct Inventory and inspect the values in the table
    expected: |
      Source settings are saved correctly:

      -   ID - is not changed;
      -   Status - is not changed;
      -   Source Name - corresponds with the updated name in Step 4 and clickable;
      -   Company - is not changed;
      -   Tags button is active, {number of added placements} value;
      -   Type - Direct Inventory (is not changed);
      -   Integration Type - is not changed;
      -   Region - is not changed;
      -   The endpoint metrics are not changed:
          
          -   Incoming QPS
          -   Bid QPS
          -   Win Rate
  - id: s-ZFS95JGV
    action: |
      Open the updated direct inventory and inspect the settings
    expected: |
      All settings are saved correctly. There are uneditable endpoint parameters on the Information page:

      -   Company name - selected on creation;
      -   Region - selected on creation;
      -   Source Type - Direct Inventory
