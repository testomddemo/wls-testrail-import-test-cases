      Open the Supply Dashboard menu item

      The 'Supply Dashboard' page is opened
  - id: s-TNN81S7E
    action: |
      -   Find the existing inventory with several added placements;
      -   Click on the tag value '{number of created placements}'
    expected: |
      The user is redirected to the placement dashboard, which consists of the following elements:

      -   {inventory name} - page name ;
      -   Search input;
      -   Filter by 'Status' - single-select dropdown with such options:
          
          -   All (selected by default)
          -   Active
          -   Not Active
      -   Filter by 'Type' - multi-select list of options:
          
          -   All (selected by default)
          -   Banner
          -   Native
          -   Video
          -   Audio
      -   'Edit source' button;
      -   'Add placement' button
      -   Column management - consists of the following columns:
          
          -   Status (selected by default)
          -   ID (selected by default)
          -   Placement (selected by default)
          -   Code (selected by default)
          -   Type (selected by default)
          -   Price (selected by default)
          -   Size (selected by default)
      -   table with placements, consists of the following elements:
          
          -   STATUS - sortable
          -   ID - sortable by default
          -   PLACEMENT - sortable
          -   CODE - not sortable
          -   TYPE - sortable
          -   PRICE - sortable
          -   SIZE - not sortable
      -   Entries Per Page — The "Show …" dropdown lets users choose how many entries to display per page, 10 by default
      -   Entry Count — The "Showing 1 to … of … entries" with the current range of entries and total number of entries
      -   Page Navigation — The "Page 1 of …" shows the current page and the total number of pages
  - id: s-5WSDXBJK
    action: |
      Click on the Status column header
    expected: |
      The sorting icon in the header will change to a descending order icon. The list will be sorted by Status: firstly all placements with the 'ON' status and then with the 'OFF' status
  - id: s-Y7D994EV
    action: |
      Click on the Status column header
    expected: |
      The sorting icon in the header will change to the ascending order icon. The list will be sorted by Status: firstly all placements with the 'OFF' status and then with the 'ON' status
  - id: s-67MZ3DJ3
    action: |
      Click on the Status column header
    expected: |
      -   The Status icon is two-way;
      -   The table is sorted by default logic, by ID in descending order
  - id: s-N6MCHHA5
    action: |
      Repeat Steps 3-5 for all sortable columns
    expected: |
      -   After the 1st click, the list will be sorted by selected column in descending order;
      -   After the 2nd click, the list will be sorted by selected column in an ascending order
      -   After the 3rd click, the icon is two-way, the table is sorted by default logic, by ID in descending order
