  - id: s-6B0FK9DJ
    action: |
      -   Click on the 'Create Source' button;
      -   Select the 'Indirect Suppliers' source type on the 'New Supply Source' page
    expected: |
      -   The 'New Supply Source' page is opened
      -   'Indirect Suppliers' source type is selected
  - id: s-EYCH1378
    action: |
      -   Select the 'VAST tag' EP type
      -   Without setting up any settings, save the endpoint
    expected: |
      The validation error appears:  
      'The General -> Source Name field is required.  
      The General -> Company field is required.  
      It’s required to select Video or Audio Ad Format.  
      It’s required to select at least one Traffic Type.'
  - id: s-NXVAQ0H8
    action: |
      -   Enter less than 3 characters in the 'Source name' field and save the endpoint
      -   Inspect the validation error only for the 'Source name' field
    expected: |
      The Validation message appears: 'The General -> Source Name must be at least 3 characters.'
  - id: s-QF9DB6MB
    action: |
      Enter more than 125 characters in the 'Source name' field and save the endpoint
    expected: |
      The validation message appears: 'The General -> Source Name must not be greater than 125 characters.'
  - id: s-286M9HAS
    action: |
      Enter the valid value in the 'Source name' field and save the endpoint
    expected: |
      The validation message appears: 'The General -> Company field is required.  
      It’s required to select Video or Audio Ad Format.  
      It’s required to select at least one Traffic Type.'
  - id: s-XF9QHGCB
    action: |
      -   Select a company;
      -   Add 1 ad format(Audio or Video) and at least 1 traffic type;
      -   Delete the 'Margin type' default value and save the endpoint
    expected: |
      The validation message appears: 'The Settings -> Margin value must be a number.'
  - id: s-TDZ8AH5Q
    action: |
      Add the invalid value (greater than 100) in the 'Margin type' field and save the endpoint
    expected: |
      The validation message appears: 'The Settings -> Margin value must not be greater than 100.'
  - id: s-EMMB3K8C
    action: |
      -   Enter the valid value in the 'Margin type' field (0 to 100);
      -   Delete the default value in the 'Bid floor Price' field;
      -   Delete the default value in the 'Spend Limit' field;
      -   Delete the default value in the 'Default TMAX' field;

      and save the endpoint
    expected: |
      -   The validation message appears: 'The Settings -> Spend Limit must be a number.
      -   The Settings -> Default TMAX field is required.
      -   The Settings -> Bid Floor Price field is required.'
  - id: s-EQGYJRYM
    action: |
      -   Add the invalid value (greater than 999999) in the 'Bid floor Price' field
      -   Add the invalid value (greater than 20000000) in the 'Spend Limit' field;
      -   Add the invalid value (greater than 4000) in the 'Default TMAX' field;

      and save the endpoint
    expected: |
      -   The validation error appears: 'The Settings -> Spend Limit must not be greater than 20000000.
      -   The Settings -> Default Tmax must not be greater than 1500. (3000 if only CTV is selected, if multiple traffic types are selected - Tmax cannot be greater than1500)
      -   The Settings -> Bid Floor Price must not be greater than 999999.'
  - id: s-8880BTP9
    action: |
      -   Enter the valid value in the 'Bid floor Price' field (0 to 999999);
      -   Enter the valid value in the 'Spend Limit' field (0 to 20000000);  
          Enter the valid value in the 'Default TMAX' field (500);
          
      -   Turn on the 'Dynamic margin' toggle in the 'Advanced Settings' and delete the default value

      and save the endpoint
    expected: |
      The validation error appears: 'The Advanced Settings -> Dynamic Margin Value field is required when Advanced Settings -> Dynamic Margin is set to true.'
  - id: s-H6SG035N
    action: |
      Enter the invalid value (greater than 100) in the 'Dynamic margin' input

      and save the endpoint
    expected: |
      The validation error appears: 'The Advanced Settings -> Dynamic Margin Value must not be greater than 100.'
  - id: s-06XXKGNM
    action: |
      Enter the invalid value (less than 0.01) in the 'Dynamic margin' input  
      and save the endpoint
    expected: |
      The validation error appears: 'The Advanced Settings -> Dynamic Margin Value must be at least 0.01.'
