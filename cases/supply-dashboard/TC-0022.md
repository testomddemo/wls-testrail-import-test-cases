      -   change the Ad Format;
      -   change the Traffic Type

  - id: s-CQT3HXAH
    action: |

    expected: |

      -   The user is still staying on the 'Edit Supply Source' page
  - id: s-PATV19BR
    action: |
      Click on the 'Save&Exit' button
    expected: |
      -   'The supply source was updated.' notification is displayed in the top right corner
      -   The user is redirected to the Supply Dashboard page
  - id: s-AWZB6NTM
    action: |
      Inspect the data in the table for the updated Supply Source
    expected: |
      All values are correct and correspond to the added values in Step 3.
  - id: s-ES7EDFN6
    action: |
      -   Select the updated Supply Source and click on its name
      -   Inspect the values in the settings
    expected: |
      -   The Endpoint Setting page is open
