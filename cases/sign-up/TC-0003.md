    action: |
      Without filling in any settings, click on the 'Sign Up' button
    expected: |
      The validation error message appears in the top right corner:

      -   'The First Name field is required.  
          The Last Name field is required.  
          The Email field is required.  
          The Password field is required.  
          The Company field is required.  
          Terms of Service & Privacy Policy must be accepted.'
  - id: s-8PJ1PBJ1
    action: |
      -   Close the validation notification;
      -   Fill in input fields 'First name' and 'Last name' the value with less than 2 chars, for example: 'a';
      -   Input invalid data in the email field (Joe Smith <[email@example.com](mailto:email@example.com)\>; [email.@example.com](mailto:email.@example.com); email@example);
      -   Input less than 8 characters in the Password field, leaving the password confirmation field empty;
      -   Enter more than 100 chars in the Company field;
      -   Check the ToS checkbox;
      -   Click the 'Join Now' button
    expected: |
      The validation error notification appears in the top right corner:

      -   'The First Name must be at least 2 characters.  
          The Last Name must be at least 2 characters.  
          The Email must be a valid email address.  
          The Password must be at least 8 characters.  
          The Company must not be greater than 100 characters.'
  - id: s-4ZXAVQ1N
    action: |
      -   Close the validation notification;
      -   Fill in input fields 'First name' and 'Last name' the value with more than 100 chars;
      -   Input the valid data in the email field with the real domain, for example, [test@gmail.com](mailto:test@gmail.com), [user1212@outlook.com](mailto:user1212@outlook.com), etc;
      -   Input 8 or more valid characters in the Password field;
      -   In the re-type password field input the password, that does not match the main Password;
      -   Input the valid value, less than 100 chars, in the Company field, for example, 'Test Company'
      -   Click the 'Sign up' button
    expected: |
      The validation error notification appears in the top right corner:

      -   'The First Name must not be greater than 100 characters.  
          The Last Name must not be greater than 100 characters.  
          The Password confirmation does not match.'
  - id: s-H0TQBAE9
    action: |
      -   Close the validation notification
      -   Fill in input fields 'First name' and 'Last name' the valid values, for example, 'Publisher', 'User';
      -   In the re-type password field input the password, that matches the main Password;
      -   Click the 'Sign up' button
    expected: |
      -   The validation errors disappear
      -   A new page opens with the message:
          
          -   Account was created!
          -   Thank you for creating an account at wls-redesign.testsmartyads.com. To complete your registration, please follow instructions from the email.
